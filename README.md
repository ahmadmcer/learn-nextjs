# BAB 1: Tentang React dan Next.js

Next.js adalah **kerangka kerja (*framework*) React** fleksibel yang memberi anda blok bangunan untuk membuat **aplikasi web** full-stack yang cepat.

Tapi apa sebenarnya yang kita maksud dengan ini? Mari luangkan waktu untuk memperluas apa itu React dan Next.js dan bagaimana mereka dapat membantu anda membangun aplikasi web.

## Blok penyusun aplikasi web

Ada beberapa hal yang perlu anda pertimbangkan saat membangun aplikasi modern. Misalnya:

- **User Interface** - bagaimana pengguna akan menggunakan dan berinteraksi dengan aplikasi anda.
- **Routing** - cara pengguna menavigasi di antara berbagai bagian aplikasi anda.
- **Data Fetching** - di mana data anda berada dan cara mendapatkannya.
- **Rendering** - kapan dan di mana anda merender konten statis atau dinamis.
- **Integrations** - layanan pihak ketiga apa yang akan anda gunakan (untuk CMS, autentikasi, pembayaran, dll) dan bagaimana anda terhubung ke layanan tersebut.
- **Infrastucture** - tempat anda menerapkan, menyimpan, dan menjalankan kode aplikasi anda (tanpa server, CDN, edge, dll).
- **Performance** - cara mengoptimalkan aplikasi anda untuk pengguna akhir.
- **Scalability** - bagaimana aplikasi anda beradaptasi seiring pertumbuhan tim, data, dan lalu lintas anda.
- **Developer Experience** - pengalaman tim anda membangun dan memelihara aplikasi anda.

Untuk setiap bagian aplikasi anda, anda perlu memutuskan apakah anda akan membangun solusi sendiri atau menggunakan alat lain, seperti paket, pustaka, dan kerangka kerja.

## Apa itu React?

**React** adalah **pustaka (*library*)** JavaScript untuk membangun **antarmuka pengguna interaktif**.

Yang dimaksud dengan antarmuka pengguna (UI) adalah elemen yang dilihat dan berinteraksi dengan pengguna di layar.

![React Components](https://nextjs.org/_next/image?url=https%3A%2F%2Fh8DxKfmAPhn8O0p3.public.blob.vercel-storage.com%2Flearn%2Fdark%2Flearn-react-components.png&w=3840&q=75)

Yang dimaksud pustaka adalah React menyediakan fungsi (API) yang bermanfaat untuk membangun UI, tetapi menyerahkannya kepada pengembang di mana harus menggunakan fungsi-fungsi tersebut dalam aplikasi mereka.

Bagian dari keberhasilan React adalah bahwa React relatif tidak berpendapat tentang aspek lain dari membangun aplikasi. Hal ini telah menghasilkan ekosistem alat dan solusi pihak ketiga yang berkembang, termasuk Next.js.

Ini juga berarti, bagaimanapun, bahwa membangun aplikasi React yang lengkap dari bawah ke atas membutuhkan beberapa usaha. Pengembang perlu meluangkan waktu untuk mengonfigurasi alat dan menemukan kembali solusi untuk persyaratan aplikasi umum.

---

## Apa itu Next.Js?

**Next.js** adalah **kerangka kerja** React yang memberi anda blok bangunan untuk membuat aplikasi web.

Yang dimaksud dengan kerangka kerja adalah Next.js menangani alat dan konfigurasi yang diperlukan untuk React, dan menyediakan struktur, fitur, dan pengoptimalan tambahan untuk aplikasi anda.

![Ecosystem](https://nextjs.org/_next/image?url=https%3A%2F%2Fh8DxKfmAPhn8O0p3.public.blob.vercel-storage.com%2Flearn%2Fdark%2Flearn-ecosystem.png&w=3840&q=75)

Anda dapat menggunakan React untuk membangun UI anda, kemudian secara bertahap mengadopsi fitur Next.js untuk menyelesaikan persyaratan aplikasi umum seperti perutean, pengambilan data, dan caching - semuanya sambil meningkatkan pengalaman pengembang dan pengguna akhir.

Baik anda seorang pengembang individu atau bagian dari tim yang lebih besar, anda dapat menggunakan React dan Next.js untuk membangun aplikasi web yang sepenuhnya interaktif, sangat dinamis, dan berperforma.

Di bab berikutnya, kita akan membahas bagaimana anda bisa memulai dengan React dan Next.js.
