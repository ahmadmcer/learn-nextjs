# Perkenalan React Foundations

Untuk mempelajari Next.js secara efektif, ada baiknya anda terbiasa dengan JavaScript, React, dan konsep pengembangan web terkait. Tapi JavaScript dan React adalah topik yang luas. Bagaimana anda tahu kapan anda siap untuk mulai menggunakan Next.js?

Selamat datang di kursus React Foundations! Kursus yang ramah pemula dan dipimpin contoh ini akan memandu anda melalui pengetahuan prasyarat untuk Next.js. Anda akan membangun proyek sederhana selangkah demi selangkah; dimulai dengan aplikasi JavaScript, lalu memigrasikannya ke React dan Next.js.

Setiap bagian dibangun di atas yang sebelumnya, sehingga anda dapat memilih dari mana harus memulai tergantung pada apa yang sudah anda ketahui.

## Pengetahuan prasyarat

Tutorial ini mengasumsikan pengetahuan tentang HTML, CSS, JavaScript, dan tidak memiliki pengetahuan tentang React. Jika anada sudah terbiasa dengan React, anda dapat melompat ke bab **Dari React ke Next.js** atau mengikuti kursus **Aplikasi Dasbor**.

## Persyaratan sistem

Sebelum anda memulai kursus ini, pastikan anda telah menginstal yang berikut ini:

- Nodejs 20.21.0 atau yang lebih baru diinstal.
- Sistem operasi: macOS, Windows (termasuk WSL), atau Linux.
- VSCode atau editor teks lain pilihan anda.
